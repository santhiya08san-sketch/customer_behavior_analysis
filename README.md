# Retail Customer Behaviour & Shopping Trends Analysis

## 📌 Project Overview
This is an End-to-End Data Analytics project focused on analysing retail customer behaviour and shopping trends using Python, PostgreSQL, Excel, and Power BI.

The project explores customer purchasing patterns, product performance, discounts, subscriptions, shipping preferences, and seasonal revenue to generate meaningful business insights.

## 🎯 Project Objectives
- Analyse customer purchasing behaviour.
- Identify top-performing products and categories.
- Understand discount and subscription patterns.
- Compare customer spending across shipping methods.
- Analyse purchase trends across different age groups and seasons.
- Build an interactive Power BI dashboard.

## 🛠️ Tools & Technologies
- **Python:** Data Cleaning, Exploratory Data Analysis (EDA), Pandas
- **PostgreSQL:** SQL Queries and Business Analysis
- **Excel:** Data Understanding and Analysis
- **Power BI:** Interactive Dashboard and Data Visualization
- **GitHub:** Project Documentation and Portfolio

## 📊 Business Analysis
The project addresses the following business questions:

1. Which customers used discounts but spent above average?
2. Which products have the highest average review ratings?
3. How do Standard and Express shipping purchase amounts compare?
4. Do subscribed customers spend more?
5. Which products have the highest percentage of discounted purchases?
6. How can customers be segmented into New, Returning, and Loyal?
7. What are the top 3 most purchased products within each category?
8. Which age group has the highest average purchase amount?
9. Which season generates the highest total purchase revenue?

## 📈 Power BI Dashboard
An interactive dashboard was developed to explore:
- Customer subscription status
- Purchase amount by category
- Customer count by category
- Revenue by age group
- Customer distribution by age
- Interactive filters and slicers
